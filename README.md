🎥 Archivio (アルキーヴィオ)

  Archivio
  は、外部データベースを一切使用せず、動画ファイルそのものの内部に情報を埋め込んで管理する、ポータビリティに特化した超軽量・動画ファイル管理アプリケーションです。

  複雑なセットアップや専用サーバー、データベースの管理は一切不要。
  「動画を移動したら情報が消えてしまった」「別の PCで開いたら一からやり直しになった」という悩みから完全に解放されます。

  ---

  ✨ 主な機能と特徴

  1. 動画ファイル自体にメタデータを完全永続化 (高ポータビリティ)
  タイトル、出演者、ジャンル（カテゴリ）、品番、レーベル、そして「評価（レーティング）」や「発売日（リリース日）」に至るまで、すべての管理情報を動画ファイルそのもののタグデータに直接保存しま
  す。
  ファイルを別のフォルダに移動しても、外付け HDD や NASにコピーしても、情報が失われることはありません。

  2. カバーアート（ジャケット画像）の埋め込み保存
  動画ファイルを象徴するジャケット画像（カバーアート）のロード、および動画ファイル内への直接埋め込み保存に対応。エクスプローラーの縮小版（サムネイル）としても美しく表示されます。

  3. 詳細な技術情報の自動スキャン
  動画を開くだけで、以下の技術情報を自動でパース・補完して一覧表示します。
   * 再生時間、解像度（フレーム幅・高さ）
   * フレームレート (fps)
   * ビデオ圧縮形式（H.264 / H.265 (HEVC) / AV1 / VP9 等）およびビットレート
   * オーディオフォーマット（AAC / MP3 / Opus / FLAC 等）およびサンプリングレート

  4. クリーン＆スマートな一覧表示と検索
  動画ファイルに埋め込まれたあらゆる情報から、瞬時に目的の動画をフィルタリング・検索。出演者やカテゴリ、評価ベースでのスムーズな動画の整理・選択が行えます。

  ---

  ⚠️ ご利用時の注意点 (制限事項)

  本アプリは「外部データベースを持たず、ファイル自身にすべてを記録する」という極めてクリーンな設計思想を採用しているため、以下の制限事項がございます。

  ① FFMpegをインストールしPathが通っている状態であればより詳細なフォーマット情報を取得できます(情報の取得はFFProbeを利用します)。FFMpegのインストールを推奨します。
   * 一部のMP4,MKVファイルではArchivioがデータを保存するエリアが壊れているケースがあります。
　　　FFMpegがインストールされていれば右クリックメニューから再MUXを実行することで再エンコードせずデータ保存可能な形に修正できる場合があります。
  ② TS / AVI などの古い形式・特殊形式における書き込み制限
   * MPEG-TS (.ts, .m2ts) / FLV形式:
     構造的にファイル内へメタデータを埋め込む領域（タグコンテナ）を持たないため、本アプリ上でのタグ・評価・カバーアート等の書き込み保存は行えません（技術情報の読み込みは可能です）。
   * AVI (.avi) / WMV (.wmv) 形式:
     ファイル構造が古く、タグ書き込みに伴うファイル破損リスク（インデックス破壊等）が非常に高いため、安全を最優先し、本アプリでは「評価」や「発売日」などの一部情報の書き込みを意図的に制限し
     ています。
   * 推奨フォーマット: 本アプリの機能をフルに活用するには、現代的なコンテナフォーマットである MP4
     (.mp4, .m4v)、MOV (.mov)、MKV (.mkv) などの動画ファイルのご利用を強くお勧めします。

  ③ 大量ファイル読み込み時のパフォーマンスについて
  外部データベース（キャッシュインデックス等）を持たない設計上、フォルダの読み込み時には毎回すべ
  ての動画ファイルに直接アクセスして、内部タグやヘッダー情報をリアルタイムで解析（スキャン）します。
  そのため、数千本規模の動画ファイルを含むフォルダや、低速な外付けHDD・NAS（ネットワークストレージ）を参照する場合、初期ロードや再読込の完了までに数分程度の時間を要する場合があります。
